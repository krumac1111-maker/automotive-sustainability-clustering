## Raw data (access & licensing)

The original WLTP/Euro 6 dataset used in this project may have redistribution restrictions.
Therefore, raw files are not shared publicly in this repository.

To reproduce the analysis:
1) Download the WLTP/Euro 6 dataset from the course/source provided.
2) Save it in this folder: `data/raw/`
3) Run the notebook(s) in `notebooks/`

This repository shares derived manufacturer-level outputs and code to support reproducibility.
